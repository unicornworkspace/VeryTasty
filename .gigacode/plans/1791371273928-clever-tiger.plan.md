# План: Создание Next.js веб-интерфейса «Особо Вкусно»

## Контекст
- Backend (Django + DRF) готов: 11 приложений, модели, миграции, auth (OTP), menu, orders, promotions, loyalty
- API endpoints доступны на `http://localhost:8000/api/`
- Требуется создать веб-фронтенд (Next.js) согласно `prototype.md` и `tech.md`

## Стек
- **Next.js 14+** (App Router) + **TypeScript** + **Tailwind CSS**
- **Zustand** — state management (cart, toast)
- **SWR** — data fetching + caching
- **Zod** — form validation
- **qrcode.react** — генерация QR-кода

## Порядок реализации (15 шагов)

### Фаза 1: Фундамент (Шаги 1-4)
1. **Инициализация проекта** — Next.js init, TypeScript, Tailwind, папки
2. **Типы + API клиент** — TypeScript interfaces, fetch wrapper с auth, Zod схемы
3. **Утилиты + хуки** — formatPrice, formatPhone, debounce, useAuth, useAPI, usePhoneMask
4. **State management** — Zustand stores (cart, toast)

### Фаза 2: UI Components (Шаги 5-6)
5. **UI Components Library** — Button, Card (DishCard, DarkCard), Input, Tabs, Stepper, Toast, Modal, Skeleton
6. **Layout Components** — Header (sticky, burger menu), Footer, AdminSidebar, AdminTopBar, root layout

### Фаза 3: Public Pages (Шаги 7-11)
7. **Главная страница (`/`)** — Hero, featured dishes (SSR), guest card preview, promotions grid
8. **Меню (`/menu`)** — Search (debounce 300ms), category tabs, dish cards grid, floating checkout button
9. **Акции (`/promo`)** — Featured banner, promo code card, promotions grid
10. **Контакты (`/contacts`)** — Address, phone, map placeholder, feedback form
11. **Авторизация** — Login modal (phone + OTP), token storage in localStorage, AuthProvider

### Фаза 4: Authenticated + Admin (Шаги 12-14)
12. **Клуб гостей (`/club`)** — Balance display, QR code (qrcode.react), history, rules (auth required)
13. **Оформление заявки (`/checkout`)** — Cart items, +/- controls, contact form with phone mask, submit to API
14. **Админ-панель (`/admin`)** — Protected layout, sidebar navigation, dashboard with summary cards

### Фаза 5: Polish (Шаг 15)
15. **Responsive + Accessibility** — Mobile-first breakpoints, WCAG 2.1 AA, keyboard nav, ARIA labels, animations

## Data Flow
```
User Action → Component → Zustand store (cart/toast)
                          → SWR/fetch (API call with Bearer token)
                          → Django API (localhost:8000/api)
                          → JSON Response → SWR cache → Re-render
```

## API Endpoints (backend → frontend)
| Endpoint | Method | Auth | Purpose |
|----------|--------|------|---------|
| `/api/menu/items/` | GET | No | Список блюд |
| `/api/menu/categories/` | GET | No | Категории |
| `/api/promotions/` | GET | No | Акции |
| `/api/auth/request-otp/` | POST | No | Запрос OTP |
| `/api/auth/verify-otp/` | POST | No | Проверка OTP + токены |
| `/api/auth/me/` | GET | Bearer | Профиль |
| `/api/orders/` | POST | No | Создать заявку |
| `/api/loyalty/me/` | GET | Bearer | Баланс (нужен бэкенд) |
