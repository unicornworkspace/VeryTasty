# Прототип WEB-сайта «Особо Вкусно»

Схематичное описание страниц с расположением блоков.

**Обозначения:**
- `[ ]` — контейнер / блок
- `( )` — кнопка
- `{ }` — изображение / медиа
- `---` — разделитель
- `→` — ссылка / переход
